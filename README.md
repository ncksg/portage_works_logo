# Portage Works Logo

Logo workshop and brand reference for Portage Works. Contains logo SVGs in multiple palette variants, standalone mark files, and a visual brand reference.

## Dev server

```
npm install
npm run dev
```

Opens on [localhost:3456](http://localhost:3456) with live-reload for HTML, SVG, and CSS changes.

## Key pages

| URL | File | Description |
|-----|------|-------------|
| `/` | `index.html` | Logo workshop — all four palette variants side by side |
| `/brand.html` | `brand.html` | Visual brand reference with dark/light toggle |

## Brand reference

- **`brand.html`** — Visual reference with color swatches, typography specimens, logo usage rules, and palette-to-context mapping. Dark/light toggle to preview each palette in context.
- **`BRAND.md`** — Machine-readable spec with named color tokens, typography rules, and logo guidelines. Designed for agent consumption.
